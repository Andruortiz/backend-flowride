FlowRide es un SaaS B2B2B para operadores de transporte corporativo con servicios programados y horarios estrictos. El
operador de transporte es el cliente de la plataforma; atiende a empresas (clientes empresariales) cuyos empleados
(pasajeros) piden un servicio, normalmente por WhatsApp. El sistema asigna un conductor con un motor de reglas
configurables, hace seguimiento del viaje y avisa a cada actor.

C# · .NET 10 · ASP.NET Core · EF Core 10 + Npgsql · PostgreSQL 17 · JWT · OpenTelemetry · xUnit · NetArchTest ·
Testcontainers · Docker.
